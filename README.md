# Задание 1.

Сразу скажу что с фронтендом особо не сталкивался ранее, пришлось поизучать, времени ушло много, но все получилось, запускается и работает.

В качестве фреймфорка используется WebPack Module Federation.

Приложение разбито на 3 микрофронтенда:
1. auth - для авторизации и регистрации
2. place - для просмотра списка мест, и операциями над ними, лайк, удаление и добавление
3. user-profile - просмотр и редактирование профиля пользователя

Микрофронтедны общаются между собой через CustomEvent.

Для запуска нужно в каждом каталоге микрофронденде выполнить команду `npm start` и в основном фронтенде host выполнить `npm start`
